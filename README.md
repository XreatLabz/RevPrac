# RevPrac

RevPrac is a Minecraft practice core plugin project for Modern Paper 1.21, created under the MIT License by XreatLabz.

The long-term goal is a StrikePractice-like practice foundation for duels, kits, arenas, queues, match lifecycle, player stats, and operator-friendly configuration. The first commit is intentionally docs-only: it establishes the project contract, repository knowledge base, and agent operating model before plugin code is scaffolded.

## Status

- Repository bootstrap: in progress
- Target platform direction: Modern Paper 1.21
- Build system: not scaffolded yet
- Plugin code: not scaffolded yet
